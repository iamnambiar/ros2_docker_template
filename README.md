# ROS2 Docker Template

A minimal Docker-based ROS2 development environment. No local ROS2 installation required.

## Requirements

- [Docker](https://docs.docker.com/get-docker/)
- [Docker Compose](https://docs.docker.com/compose/install/)

## Configuration

Edit `.env` to configure:

| Variable | Default | Description |
|---|---|---|
| `IMAGE_NAME` | `ros2-dev` | Docker image name |
| `ROS_DISTRO` | `rolling` | ROS2 distribution |
| `ROS_DOMAIN_ID` | `0` | ROS2 domain ID |

## Usage

```bash
./run.sh build    # Build the Docker image
./run.sh start    # Start an interactive shell
./run.sh up       # Build and start in one go
./run.sh help     # Show available commands
```

### Inside the container

```bash
# Install dependencies
rosdep install --from-paths src --ignore-src -r -y

# Build
colcon build

# Run a node
ros2 run <package> <executable>
```

## GUI Applications

Allow the container to access your X server before starting:

```bash
xhost +local:docker
```

GUI apps (RViz, Gazebo, rqt) will display on your host desktop.

## Workspace Layout

```
your_ws/
├── src/        # ROS2 packages go here
├── build/      # Generated by colcon (bind-mounted)
├── install/    # Generated by colcon (bind-mounted)
└── log/        # Generated by colcon (bind-mounted)
```

`build/`, `install/`, and `log/` are bind-mounted so build artifacts persist across container restarts.
